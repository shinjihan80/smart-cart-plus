  lens: "PWA 오프라인·설치가 실제로 되는가 / 유실 경로가 또 있나"

## 검토 범위 밖 / 확인 못 한 것
- 오프라인 실사용(기기 네트워크 차단) 검증은 이 환경에서 못 했다 — SW 코드와 캐시 상태만 확인.
- 백업 **복원** 경로는 실제 파일 업로드가 필요해 미실행. 다만 복원이 병합이 아닌 전체 교체(`setItems(snapshot.items)`)이고, 복원 전 현재 상태를 따로 떠두지 않는다는 점은 확인했다.
