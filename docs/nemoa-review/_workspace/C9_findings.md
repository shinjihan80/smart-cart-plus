# C9 (강병철 54 / 회사원·부부 2인 · 디지털 중급) — 재검토

대상: https://nemoa.vercel.app (커밋 317c778) · 신규 알림함 집중 + 옷장/코디 훑어봄

- screen: 알림(/notifications) > 알림 목록 카드
  observed: "⏰ 오늘 소비해야 할 식품 2개 / 우유, 계란 / 오전 08:18" 카드를 눌러도 반응 없음. 접근성 트리에서 `generic`일 뿐 버튼·링크 아님. 소스 확인: `<div>`로 onClick 없음. 이 화면에서 누를 수 있는 건 뒤로/휴지통/배너 셋뿐.
  problem: 알림을 읽고 나면 그 항목(냉장고의 우유)을 보러 가고 싶은데 카드가 안 눌려서 다시 냉장고 탭에서 찾아야 함.
  lens: 다음 행동이 명확한가
  priority_guess: P1

- screen: 알림(/notifications) > 카드 제목 truncate
  observed: "⏰ 오늘 소비해야 할 식품 …"로 잘림 — 하필 개수("2개")가 잘림. 제목·본문 모두 한 줄 truncate, 펼치기 불가(카드 자체가 안 눌림).
  problem: 몇 개가 급한지가 알림의 핵심인데 그 숫자가 안 보이고 펼칠 방법도 없음.
  lens: 라벨이 분명한가 / 다음 행동이 명확한가
  priority_guess: P1

- screen: 알림(/notifications) > 헤더 우측 휴지통(전체삭제)
  observed: 글자 라벨 없이 아이콘만(aria-label만 존재, 화면엔 안 보임). onClick={clear} 확인창 없이 즉시 전체 삭제, 되돌리기 없음.
  problem: "닫기/더보기" 자리인 줄 알고 눌렀다가 전부 삭제될 위험. 확인 단계 없음.
  lens: 라벨이 분명한가 / 다음 행동이 명확한가
  priority_guess: P1

- screen: 알림 배너 ↔ 설정 > 알림 설정 — 용어 불일치
  observed: 알림 화면 배너="알림이 꺼져 있어요/설정에서 켜면", 설정 화면="알림이 차단됐어요/휴대폰 설정>앱>NEMOA>알림에서". "설정"이 앱 설정인지 폰 설정인지 배너엔 안 나와 있고, 앱 설정 들어가면 또 폰 설정으로 안내 — 두 번 헛걸음.
  problem: 같은 상태를 두 다른 용어("꺼짐"/"차단")로 불러 다른 문제로 오인.
  lens: 다음 행동이 명확한가 / 분명한 한국어인가
  priority_guess: P1

- screen: 홈 헤더 종 ↔ 알림 목록 — 안읽음 표시
  observed: 안읽음 점이 8px 아주 작고 숫자 없음. 목록 열면 즉시 markAllRead() 실행되는데 두 카드가 읽음/안읽음 구분 없이 동일하게 렌더.
  problem: 점이 화면 얼룩처럼 안 보이고, 몇 개가 새 알림인지도 안 나옴. 목록을 봐도 어느 게 새 건지 알 수 없음.
  lens: 라벨이 분명한가 / 다음 행동이 명확한가
  priority_guess: P2

- screen: 알림 카드 아이콘·제목 — 이모지 중복
  observed: 원형 아이콘(⏰/👗)과 제목 텍스트("⏰ 오늘 소비해야 할 식품…") 양쪽에 같은 이모지가 중복. 좁은 화면에서 이모지가 제목 자리를 2칸 차지해 "2개"가 잘리는 원인 중 하나. "코디"라는 용어에 설명 없음.
  problem: 정보 중복 + 정작 필요한 숫자가 밀려남. 전문용어("코디") 미설명.
  lens: 이모지가 정보 전달에 쓰이는가 / 전문용어 설명
  priority_guess: P2

- screen: 옷장 탭 · 코디 탭 — 훑어본 결과
  observed: "옷장"이라는 단어가 한 화면에 4번(하단메뉴/제목/탭/옷장1) 등장, 옷장 탭과 의류 탭 차이 설명 없음. 옷장 탭 카드는 이름 없이 이모지만(👕👕 두 개가 어느 옷인지 구분 불가). 코디 탭 라벨 "셔츠 × 데님"의 × 기호 의미를 한참 생각해야 했음(곱하기로 오인). "카드에서 '오늘 입었어요'로 기록" 안내문이 있는데 정작 보이는 카드엔 그런 버튼이 없어(상세 모달에만 있음) 어디를 말하는지 못 찾음.
  problem: 정보구조 혼란("옷장" 중복) + 이름 없는 이모지 목록(카테고리는 알아도 내 옷 식별 불가) + 안내문과 실제 UI 위치 불일치.
  lens: 탭 라벨 명확성 / 이모지 정보전달 / 전문용어 설명
  priority_guess: P1
