## 검토 환경 메모 (오케스트레이터 참고)
- 내장 브라우저의 localStorage가 병렬 세션과 공유돼서, 검토 중 아이템이 41→0→1("우유", manual-…)로 다른 세션 데이터에 덮어쓰였다. 샘플을 다시 불러와 진행했다. **앱 버그 근거 없음.**

- `computer` 좌표 클릭이 모바일 에뮬레이션에서 약 0.66배로 어긋나 들어가서(654,1136 → CSS 434,754), 확인은 JS 클릭과 elementFromPoint로 했다. ›→배너 숨김은 좌표 클릭으로 실제 재현했다.
- ConsentGate의 "샘플 41개로 체험해보기"를 눌러 로컬 동의 플래그(nemoa-consent-v1)가 생겼다. 테스트용 데이터만 썼다: "다 먹었어요" 1건 실행, 등록 폼은 입력만 하고 저장 안 함.
