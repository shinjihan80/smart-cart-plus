# C1 findings — 김도현 24 / 대학생·자취 1년차 (귀찮음 최소주의)

- 대상: https://nemoa.vercel.app (라이브, 2026-10-21 오후 KST 확인), 모바일 375×812
- 범위: 홈 · 냉장고 · 옷장 · 마이 · 등록 · 요금제 (모드: UI/UX 중심 비판 — 흐름·상호작용·문구↔동작 일치)
- 이전 C1 산출물: 2026-10-20 판(8건). 그 뒤 main에 새 커밋이 없어서 대부분 그대로다. 아래에서 각 항목에 [미해결 / 부분 해소 / 신규]를 붙였다.
- 사용 패턴: 첫 방문 동의 시트 → + → 직접입력 "계란" 등록 → 냉장고 음식 탭 → 날짜를 고쳐 기한 초과로 만들기 → 홈 배너 "확인하기" → 상해서 버렸어요 / 장보기 빠른 추가 / 마이 요금제 / 설정 클라우드 백업 → 업그레이드 시트
- 참고: 브라우저 프로필(localStorage)을 다른 검토 에이전트와 같이 쓴다. 그래서 검토하는 동안 품목 수가 20→23으로 오르내렸다. 아래 수치는 한 화면에서 같은 시점에 함께 보인 값만 인용했다.
- 시험 데이터: 직접입력으로 "계란"을 추가한 뒤 유통기한을 10/19로 고쳐 기한 초과로 만들었고, "상해서 버렸어요"로 처리했다. 장보기 빠른 추가로 넣은 "요거트" 1개는 남아 있다(삭제 수단이 없음, #4 참고).

  lens: 홈에서 뭘 눌러야 할지 5초 / 배너 때문에 이탈하고 싶은가

확인했지만 C1 기준으로 문제가 없었던 것: 첫 방문 동의 시트는 [동의하고 빈 상태로 시작]과 [샘플 41개로 체험해보기] 중 하나만 고르면 끝나고, 빈 상태 홈의 "처음이신가요? — 첫 항목 등록하기"는 바로 이해된다. 광고 배너나 전면 광고는 웹에서 보지 못했다. 직접입력 등록은 +, 식품 등록, 이름 입력, 1개 추가하기 순서로 3탭 안에 끝나고 카테고리와 기간도 자동으로 채워진다. '상해서 버렸어요' 토스트에는 되돌리기가 있다. 옷장 화면과 홈 '오늘 코디'는 C1이 쓰지 않아서 지적하지 않았다. 마이의 통계(요약 탭)는 C1이 무시하는 영역이라 정확도를 보지 않았다.
