B · 실기기 확인 이건 직접 봐줘

dev 프리뷰가 재현 못 하거나(터치·safe-area·백그라운드 복귀), 눈으로 봐야 판단되는 것. 안드로이드 에뮬레이터/실기기에서.

1 N-4마이페이지 하단 내비 — 핵심
  1. 내 정보 탭 → 사용자 탭에서 "프로필 전환" 버튼 탭 (시트 열림)
  2. 시트 바깥 어두운 곳을 탭해서 닫기
  3. 바로 하단 내비의 냉장고 · 옷장 · 홈 각각 눌러보기전부 정상 이동. 안 눌리거나 화면이 살짝 어두우면 아직 버그
  4. 빠르게 열었다 닫기 5~6번 반복 후 다시 내비 탭
2 P0-9폴더블 / 노치 — 헤더·탭바 위치
  1. 냉장고 · 옷장 · 내 정보 각 화면 상단
  2. 화면 제목("스마트 냉장고" 등)이 상태바 시계와 안 겹치는지시계 아래로 내려와 있음
  3. 하단 탭바 아이콘·라벨이 제스처 핸들바에 안 잘리는지, 등록(+) 버튼이 겹치지 않는지

  2. 홈 그리드의 냉장고 아이콘 배지 숫자 = 하단탭 냉장고 배지 숫자같은 숫자. "긴급"·"임박" 용어 섞이지 않음

  2. "오늘 입을 코디" 카드에서 상의·하의가 크게, 신발·반지가 우측에 작게반지가 티셔츠와 같은 크기 아님
  3. 카드 하단에 실제 옷 이름이 나오는지 (예: "리넨 셔츠 · 청바지 · 로퍼")
