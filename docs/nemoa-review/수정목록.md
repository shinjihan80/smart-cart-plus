## 0. 검토 대상 요약 (공통 인식)

- **정체성**: 집안 살림(냉장고 식품 + 옷장 의류)을 한 앱에서 관리하는 PWA/Android(TWA). 데이터는 폰 localStorage에 저장, JSON 백업으로 기기 이전. 단, 설정에 "로그인 클라우드 동기화" UI가 노출돼 있어 포지셔닝이 모순(→ P0-12).
- **핵심 기능**: ①냉장고(유통기한·보관위치·레시피 추천) ②옷장(코디 추천·사이즈 매칭·계절보관) ③AI 자동등록(사진/텍스트/URL) ④알림(임박·날씨) ⑤마이(통계·영양·지출·재구매주기)
- **부가 기능**: 제철, 레시피, 쇼핑(외부몰 링크 — 제휴 추정), 활동, 프로필(가족 구성원)
- **수익모델**: 베이직(무료) + Pro Lite ₩4,900/월·Pro Max ₩9,900/월 (요금제 탭 표기, "결제 연동 출시 예정" `PAYMENTS_ENABLED=false`). **광고는 라이브(`357fe2c`)에서 제거됨** — 2026-08-27 재확인.

### 페르소나 상세

**C1 김도현 (24)** — "앱 켜서 3초 안에 답 안 나오면 그냥 안 봐요." 무료만 쓸 생각. 하단 고정 광고 배너와 전면 광고에 즉시 이탈. 홈에 아이콘이 8개+탭 5개면 "뭘 눌러야 되는지 모르겠다". 알림도 하루 1개면 충분, 3단계로 오면 끔.

**C2 이서연 (27)** — 옷장·코디가 메인 관심. 이모지로 옷을 표현한 코디 카드(티셔츠·청바지·운동화·반지 이모지)가 "장난감 같다". 다크모드 없음에 실망. 코디를 이미지로 저장/공유하고 싶음. 브랜드 색(보라 그라데이션)은 마음에 듦.

**C3 박준영 (22)** — 회원가입 없는 건 좋음. 그런데 마이페이지에서 키·몸무게·식습관을 요구하는 이유를 모름 → "이거 어디 가는 거냐". "폰에만 저장" 문구가 도움말 깊숙이 있어서 못 봄. 알림 권한, 카메라 권한 요청 시 맥락 설명을 원함.

**C4 최지은 (34)** — 아이·남편 것을 프로필로 나눠 관리하려는데 프로필 추가 흐름이 어디 있는지 헤맴("설정"에도 "마이"에도 프로필이 있음). 알림이 실제 유통기한과 안 맞으면 바로 신뢰 상실. 장보기 → 쿠팡/컬리 연동은 매우 좋아함.

**C5 정민우 (31)** — "브라우저 캐시 지우면 날아간다"는 경고를 보고 바로 불안. 자동 백업이 없고 수동 JSON뿐인 게 리스크. 요약 탭마다 숫자가 다른 것(사용자 탭 0개 / 요약 탭 41개)을 버그로 지목. PWA 오프라인·홈 화면 추가·알림이 iOS에서 실제로 되는지 의심.

**C6 한소희 (38)** — 탭 라벨의 이모지(🧊🍽️💡🛒👕)가 OS마다 다르게 렌더링되고 "디자인 시스템이 없어 보인다". 카드 그림자·모서리 반경·회색 텍스트 대비가 화면마다 제각각. 홈 배너에 경고 삼각형 아이콘이 두 개(좌측 작게 + 우측 크게)라 시각적으로 시끄러움.

**C7 오세훈 (45)** — "요약"에서 지출·재구매 주기를 보고 싶은데 숫자가 0이거나 화면마다 달라 신뢰가 안 감. "소진 처리 0건"이면 이 앱이 실제로 뭘 아껴줬는지 증거가 없음. Pro 월 4,900원이 뭘 더 주는지 한눈에 안 옴.

**C8 윤미경 (42)** — 임박 위젯은 좋아함. 다만 홈 배너 문구 "친환경 샐러드 믹스 외 2개이(가) 오늘 내로..."에서 조사(이/가)가 깨져 있고 줄바꿈이 단어 중간에서 끊김. 냉장고 카드에서 "도어 중간 포켓"이 "포/켓"으로 잘림. 글자가 전반적으로 작음.

**C9 강병철 (54)** — 하단 탭 "마이"가 무슨 뜻인지 모름("마이 뭐?"). "코디", "AI 자동 등록" 같은 용어도 설명이 필요. 버튼은 크고 라벨은 서술형(예: "지금 백업하기")이면 좋음. 영어·이모지 줄이고 한국어로.

**C10 서정숙 (58)** — 앱을 처음 열면 배너·아이콘·탭·광고가 한꺼번에 보여 "어디를 눌러야 시작인지" 모름. 온보딩(따라 하기) 없음. 실수로 삭제할까 봐 등록 자체가 무서움. "되돌리기"가 있다는 걸 모름. 문제 생기면 전화할 곳을 찾는데 없음(Pro에만 문의 채널).

# Part 2. 전문단 (20년차 3인)

## E1. 20년차 서비스 기획자 — 김태원
**관점**: 정보구조 / 온보딩 / 리텐션 / 수익모델 / 기능 우선순위 / PMF

주요 지적:
- **IA 중복·과잉**: 홈 8-아이콘 그리드 + 하단 5-탭에서 냉장고·옷장이 중복. 진입 경로가 2개면 학습 비용만 늘고 분석도 흐려진다. 하단 탭은 4~5개로 고정하고, 홈 그리드는 "덜 쓰는 기능"만 남기거나 없앤다.
- **뱃지 숫자 불일치**: 하단 탭 냉장고 뱃지(7)와 홈 그리드 냉장고 뱃지(20)가 다른 값. 하나는 "임박", 하나는 "전체"로 추정되나 사용자는 구분 못 함. 뱃지는 "행동이 필요한 수"로 통일.
- **미출시 기능 노출**: "클라우드 동기화 준비 중", "요금제 출시 예정", "Pro 단계에서 문의 채널" 등 없는 걸 여러 곳에서 약속. 기대만 키우고 실망 유발. 미출시는 숨기거나 1곳에서만 "관심 등록".
- **수익모델 메시지 충돌**: Pro 모달은 "베이직도 광고 없음"이라는데 실제 앱에는 하단·전면 광고가 있음. 즉시 신뢰 훼손. 광고 정책을 먼저 확정(무료=광고 있음 / Pro=광고 제거)하고 카피를 일치시킨다.
- **요금제 구조 불명확**: Pro 단일(4,900원) vs Pro Lite/Pro Max 2단계가 화면마다 다름. 플랜은 하나의 소스에서 정의하고 비교표를 기본 노출.
- **온보딩 부재**: 첫 실행 시 "냉장고에 1개 등록해보기" 같은 3스텝 가이드가 없다. 초기 활성화(빈 상태 → 첫 등록) 전환이 리텐션의 8할.
- **가치 증명 부재**: "소진 처리 0건", 지출 0원처럼 앱이 절약해준 금액/버린 음식 감소를 보여주는 지표가 비어 있음. 이게 재방문 이유인데 공란.
- **핵심-부가 경계 흐림**: 제철·레시피·활동은 부가인데 홈 상단을 차지. 냉장고·옷장이라는 두 축을 먼저 단단히.

## E2. 20년차 프론트엔드/풀스택 개발자 — 이현석
**관점**: 성능 / PWA·오프라인 / 로컬 저장 한계 / 데이터 무결성 / 접근성 구현 / 에러 핸들링

주요 지적:
- **데이터 유실 리스크**: localStorage/IndexedDB만 사용 + 수동 JSON 백업. Safari의 7일 미방문 스토리지 정리, 캐시 삭제, 기기 분실 시 전량 손실. 최소한 ①자동 주기 백업 리마인드 ②백업 파일 자동 공유 시트 ③(로그인 없는) 익명 클라우드 스냅샷 옵션 필요.
- **통계 계산 버그**: "사용자" 탭 활동요약 0/0/0 vs "요약" 탭 41/20/21. 동일 소스에서 파생돼야 할 값이 다름 → selector/집계 로직 분리로 인한 불일치. 단일 파생 셀렉터로 통합.
- **전면 광고 실패 처리 없음**: 광고 로드 실패 시 거대한 빈 흰 모달만 노출(닫기 버튼만). 로드 실패/타임아웃 시 모달 자체를 렌더하지 않아야 함.
- **시간대/인사말 로직**: 새벽 1:22에 "점심 시간이에요", 오전 11시대에 "좋은 아침이에요" 표시. 시간 구간 매핑 오류 또는 서버 시간 사용 의심.
- **문자열/조사 처리**: "…외 2개이(가)" — 한국어 조사 자동 선택(을/를, 이/가, 은/는) 유틸 부재. 받침 판별 헬퍼로 일괄 처리.
- **텍스트 오버플로우**: 냉장고 카드 제목 "도어 중간 포켓" 등 다수가 클리핑. line-clamp + 툴팁/펼침 필요. 메이슨리 카드 높이 불규칙으로 스캔성 저하.
- **접근성 구현**: 터치 타깃 상당수가 36px(w-9 h-9)로 44px 미만. 회색 텍스트(gray-400) + text-xs 조합이 WCAG AA 대비 미달. 이모지를 정보 전달에 사용(스크린리더가 "눈사람" 등으로 읽음) — aria-label 또는 아이콘 컴포넌트로 대체.
- **PWA 검증**: iOS에서 Web Push는 홈 화면 추가 + iOS 16.4+ 조건. "알림이 안 와요" FAQ가 있다는 건 이미 알려진 문제. 설치·권한 흐름을 앱 내에서 단계별로 안내.
- **번들/로드**: framer-motion 다수 화면 사용 + 하단 광고 SDK. 초기 로드·상호작용 지연 측정(Lighthouse/Speed Insights) 후 모션 축소·지연 로드.

## E3. 20년차 UX/UI 디자이너 — 박세라
**관점**: 비주얼 시스템 / 타이포·컬러·간격 / 인터랙션 / 대비·접근성 / 카피 톤앤매너

주요 지적:
- **아이콘 언어 이원화**: 브랜드 아이콘(라인 아이콘, lucide)과 이모지가 섞여 있음. 탭·섹션 제목의 이모지를 전부 라인 아이콘으로 통일. 코디 카드의 옷 이모지는 실제 썸네일(누끼 이미지) 또는 통일된 일러스트로.
- **경고 남용**: 홈 배너에 ⚠️ 2개 + "주의" 배지. "점심 시간이에요"는 위협이 아니라 제안. 톤을 정보/제안 레벨로 낮추고 경고색(빨강)은 진짜 위험(유통기한 초과)에만.
- **공포 마케팅 배너**: 붉은 "데이터가 사라질 수 있어요" 배너가 마이·설정·요금제·요약 등 거의 모든 화면 상단에 반복. 1회성 안내 + 마이페이지 한 곳으로. 색은 경고 아님 → 중립/정보 톤.
- **타이포 스케일 부재**: text-xs / gray-400 남발로 본문이 흐리고 작음. 최소 본문 14~16px, 보조 텍스트도 대비 4.5:1 확보. 제목-본문-보조 3단계 스케일 정의.
- **간격·컴포넌트 불일치**: 카드 radius(2xl vs 32px), 그림자 강도, 헤더 높이, 검색 아이콘 유무가 화면마다 다름. 헤더·카드·리스트 아이템을 공용 컴포넌트로.
- **카피 톤앤매너**: "마이"(→ "내 정보"), "코디"(유지하되 최초 1회 설명), 영문 혼용 정리. 문장형 버튼("지금 백업하기")은 좋은 방향 — 전체로 확장.
